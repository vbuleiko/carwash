# Washbook — журнал автомойки с WhatsApp

Веб-приложение для ручных автомоек (ЮАР): вместо листочка — телефон.
Машину записали → назначили мойщиков → нажали **Ready** → открылся WhatsApp с готовым текстом «ваша машина готова».
Плюс выручка, скорость мойщиков, лояльность и отзывы.

Интерфейс и лендинг — на английском. Мультитенантность: каждая мойка регистрируется сама и видит только свои данные.

## Что умеет

| Для владельца мойки | Для тебя (владельца сервиса) |
|---|---|
| Доска: Waiting → Washing → Ready → Collected, таймеры | Лендинг с ценой и FAQ |
| Приём машины: номер, марка, телефон, тип авто, услуги, цена по прайсу. **Скан license disc камерой телефона** — номер, марка и тип заполняются сами | **Демо без регистрации** («тестовый контур»): песочница с 2 неделями данных, стирается через 24 ч |
| Постоянные клиенты подставляются по номеру авто | Регистрация мойки → 30 дней триала |
| **Ready** → открывает WhatsApp (wa.me) с текстом, отправка с телефона мойки — бесплатно | `/admin`: все мойки, триал/оплата, +1/+12 месяцев, пауза, сброс пароля, «открыть как владелец» |
| Мойщики без логинов: выбираются при старте мойки | Сколько машин в день реально проходит через каждую мойку |
| Отчёты: выручка, машины, средний чек, время мойки, загрузка по часам и дням | |
| Мойщики: скорость относительно обычного времени **на ту же услугу и тип авто**, заработок (% или R за машину, делится на команду) | |
| Лояльность «каждая N-я мойка бесплатно» по номеру авто | |
| Запрос отзыва Google одной кнопкой после выдачи | |
| Прайс: услуга × тип авто (Hatch/Sedan, SUV, Bakkie, Minibus) | |
| **Онлайн-запись**: своя страница `/book/<мойка>` — клиент выбирает тип авто, услуги, день и время; запись появляется во вкладке Bookings, подтверждение — в WhatsApp | На лендинге — макет страницы записи и кнопка «See a booking page» (открывает её в демо) |

Подписка оплачивается вручную (EFT): мойка жмёт «Subscribe on WhatsApp», ты получаешь деньги и продлеваешь в `/admin`. Когда срок истёк — данные видны, но новые машины добавлять нельзя.

## Стек

Python 3.12 · Flask · SQLite · серверные шаблоны + ~200 строк JS · без внешних CDN.
Продакшн: Docker + Caddy (бесплатный HTTPS от Let's Encrypt автоматически).

```
app/
  __init__.py   настройки, заголовки безопасности
  owner.py      приложение мойки (/app)
  public.py     лендинг, регистрация, вход, демо
  admin.py      твоя админка (/admin)
  reports.py    отчёты и скорость мойщиков
  queries.py    общие запросы, лояльность, тексты WhatsApp
  seed.py       стартовый прайс и демо-данные
  db.py         схема SQLite
  templates/ static/
tests/          pytest
deploy/         скрипты для виртуалки
```

## Запуск локально

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
ADMIN_PASSWORD=admin flask --app app run --debug    # http://127.0.0.1:5000
pytest                                               # тесты
```

База создаётся в `./data/washbook.db`.

## Деплой на Google Cloud (Compute Engine)

Регион `africa-south1` — Йоханнесбург, ближе всего к клиентам.

**1. Виртуалка** (в Cloud Shell или локальном `gcloud`):

```bash
gcloud config set project ТВОЙ_ПРОЕКТ
gcloud compute addresses create washbook-ip --region=africa-south1
gcloud compute instances create washbook \
  --zone=africa-south1-a --machine-type=e2-small \
  --image-family=debian-12 --image-project=debian-cloud \
  --boot-disk-size=20GB --tags=web --address=washbook-ip
gcloud compute firewall-rules create washbook-web \
  --allow=tcp:80,tcp:443,udp:443 --target-tags=web
gcloud compute addresses describe washbook-ip --region=africa-south1 --format='value(address)'
```

Если `e2-small` недоступна в зоне — возьми соседнюю зону или другой небольшой тип. Приложению хватает 1–2 ГБ памяти.

**2. Домен.** В DNS добавь A-запись `washbook.co.za → IP` из прошлого шага.

**3. Установка** (на виртуалке: `gcloud compute ssh washbook --zone=africa-south1-a`):

```bash
sudo apt-get update && sudo apt-get install -y git
git clone https://github.com/vbuleiko/carwash.git   # репозиторий приватный: нужен токен GitHub или deploy key
cd carwash
bash deploy/setup-vm.sh          # ставит Docker, создаёт .env со случайным SECRET_KEY
nano .env                        # DOMAIN, ADMIN_PASSWORD, SUPPORT_WHATSAPP
sudo docker compose up -d --build
```

Через минуту открой `https://твой-домен` — сертификат Caddy получит сам. Админка: `https://твой-домен/admin`.

Без домена (только проверить): в `.env` поставь `DOMAIN=:80` и `COOKIE_SECURE=0`, открой `http://IP`. Для настоящей работы нужен домен: без HTTPS пароли идут открытым текстом и не работает «Add to Home Screen».

**Обновление:** `bash deploy/update.sh` (git pull + пересборка).

**Бэкапы:** `bash deploy/backup.sh` — копия базы в `backups/` (хранится 14 дней). Каждую ночь через `crontab -e`:

```
30 1 * * * /home/ТВОЙ_ЮЗЕР/carwash/deploy/backup.sh >> /home/ТВОЙ_ЮЗЕР/carwash/backups/backup.log 2>&1
```

Чтобы копии уходили ещё и в Cloud Storage, добавь в `.env` `BACKUP_BUCKET=gs://имя-бакета`. У сервисного аккаунта виртуалки должно быть право записи в бакет.

## Настройки (.env)

| Переменная | Что это |
|---|---|
| `DOMAIN` | домен сайта (для Caddy/HTTPS) |
| `SECRET_KEY` | длинная случайная строка (подписывает сессии) |
| `ADMIN_PASSWORD` | пароль к `/admin`; пусто = админка выключена |
| `SUPPORT_WHATSAPP` | твой номер, цифры с кодом страны (кнопки «Contact / Subscribe») |
| `SUPPORT_EMAIL` | почта поддержки (необязательно) |
| `PRICE_MONTHLY` | цена на лендинге, по умолчанию `R299` |
| `TRIAL_DAYS` | длина триала, по умолчанию 30 |
| `APP_NAME` | название продукта, по умолчанию `Washbook` |
| `THEME` | оформление по умолчанию для лендинга и новых моек: `carbon` (по умолчанию), `volt`, `midnight`, `noir`, `classic` |
| `SITE_MODE` | `1` — сайт одной мойки: на `/` её страница записи, регистрация и демо выключены |
| `COOKIE_SECURE` | `1` на HTTPS (норма), `0` только для теста по http |

## Онлайн-запись

Страница записи мойки: `https://домен/book/<адрес>` (адрес меняется в **Settings → Online booking**, там же часы работы и сколько машин можно принять на одно время). Клиент выбирает тип авто, одну или несколько услуг, день и время (шаг 30 минут, на две недели вперёд) и оставляет имя и WhatsApp. Владелец видит запись во вкладке **Bookings** (на доске — «Booked today»), жмёт **Confirm** — открывается WhatsApp с текстом подтверждения. Когда клиент приехал — **Arrived**: открывается «New car», уже заполненная из записи.

### Сайт одной мойки на её домене

Если мойка покупает свой сайт, ставишь отдельную копию на её виртуалку так же, как в разделе «Деплой», и в `.env` добавляешь:

```
SITE_MODE=1
DOMAIN=sunshinecarwash.co.za
THEME=noir                # тема по умолчанию (владелец может сменить в Settings → Look)
```

На корне домена открывается страница записи этой мойки, приложение — на `/app`. При первом заходе `/` ведёт на `/signup`: там создаёшь аккаунт мойки (один на сайт). После этого регистрация и демо отключены. Подписка работает как обычно: продлевай в `/admin` (нужен `ADMIN_PASSWORD`) или поставь большой `TRIAL_DAYS`.

## Скан license disc

На экране «New car» есть кнопка **Scan licence disc**: камера читает PDF417-штрихкод диска на лобовом стекле и заполняет номер, марку с моделью и тип авто. На Android работает встроенный сканер Chrome, на iPhone — свой декодер из `app/static/vendor/` (~1 МБ, грузится только при нажатии). Камера в браузере работает только по **HTTPS** (или на `localhost`), поэтому с телефона по `http://IP` кнопки не будет.

## Оформление

Пять тёмных тем: Carbon, Volt, Midnight, Noir и Classic. Владелец выбирает тему в **Settings → Look**, она сохраняется в аккаунте мойки. На лендинге посетитель может переключить тему кружками под макетом телефона, выбор запоминается в браузере и переходит в демо и в новую мойку при регистрации.

## Как устроено демо

Кнопка **Try the live demo** на лендинге создаёт отдельную мойку-песочницу (Sunshine Car Wash) с ~2 неделями истории и машинами на доске. Вместо открытия WhatsApp показывается превью сообщения, чтобы демо не писало на случайные номера. Песочницы удаляются через 24 часа. Лимиты: 10 демо в час с одного IP, не больше 300 одновременно.

## Что дальше (не в этой версии)

- Скан лицензионного диска (штрихкод → марка и номер)
- Работа без интернета с синхронизацией
- Автооплата подписки (PayFast / Paystack)
- Восстановление пароля по email (сейчас сбрасываешь сам в `/admin`)
- Несколько точек у одного владельца

Политика конфиденциальности на `/privacy` — шаблон под POPIA. Перед запуском её стоит показать юристу.
